# BSCS Programming Practice (C++)

This repository contains C++ programming practice files and assignments organized by topic for BSCS Programming Fundamentals and practice.

## Current & Upcoming Topic Roadmap

### 1. C++ Basics & Fundamentals
- `CPP Basic/` – Program structure, execution flow, variables, data types, input/output (`cin`/`cout`), constants, local vs. global variable scope, and operators/precedence.

### 2. Control Flow & Loops
- `CPP If Statement/` – Conditional statements (`if`, `else if`, nested `if`, and `switch-case`).
- `CPP For Loop/` – `for` loop exercises and iterative problem-solving.
- `CPP While and Do While Loop/` – `while` and `do-while` loop exercises and iteration logic.

### 3. Functions & Modularity *(Upcoming)*
- `CPP Functions/` – Function declarations, definitions, call stack execution, call by value vs. call by reference, and scope/lifetime.

### 4. Arrays, Strings & Pointers *(Upcoming)*
- `CPP Arrays and Strings/` – 1D/2D arrays and string handling exercises.
- `CPP Pointers/` – Pointer basics, memory addresses, and pointer operations.

### 5. Object-Oriented Programming (OOP) *(Upcoming)*
- `CPP OOP/` – Classes, objects, constructors, inheritance, and operator overloading.

## Workflow & Ignored Files
- Compiled binaries (`.exe`, `.o`, `.obj`, `.out`) and IDE/build temporary files are ignored via `.gitignore`.
- New programs are added to their relevant topic folders and synced to GitHub via commit and push.
